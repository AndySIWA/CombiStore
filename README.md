# CombiStore 🚀

**CombiStore** est une application mobile et web développée avec **React Native**, **Expo** et **TypeScript**. Elle offre un magasin centralisé et un lecteur fluide d'applications web légères (Mini-Apps), avec synchronisation cloud et personnalisation d'expérience utilisateur.

---

## ✨ Fonctionnalités Principales

* 📱 **Magasin de Mini-Apps** : Parcourez, recherchez et découvrez des applications web optimisées.
* 📂 **Gestion des Catégories** : Filtrage dynamique des applications par domaines d'intérêt.
* ⭐️ **Système de Favoris** : Sauvegarde locale instantanée et synchronisation automatique via Firebase Firestore.
* 🌐 **Lecteur WebView Intégré** : Exécution fluide et sécurisée des applications web directes ou hébergées.
* 🛠️ **Création & Gestion d'Apps** : Ajoutez vos propres applications web personnalisées via URL ou fichier HTML.
* 🌙 **Thème Dynamique & Animations** : Interface moderne avec support du mode Sombre / Clair et animations fluides (Reanimated v4).
* ☁️ **Intégration Sanity CMS** : Catalogue de contenu administrable à distance.

---

## 🚀 Démarrage Rapide

### Prérequis
* Node.js (v18 ou supérieur)
* npm ou yarn
* Application Expo Go (mobile) ou un émulateur Android/iOS

### Installation

```bash
# 1. Cloner le projet
git clone https://github.com/AndySIWA/CombiStore.git
cd CombiStore

# 2. Installer les dépendances
npm install
```

### Lancement du projet

```bash
# Lancer l'environnement de développement Expo
npm run start

# Lancer la version Web
npm run web

# Vérifier le typage TypeScript
npm run typecheck
```
